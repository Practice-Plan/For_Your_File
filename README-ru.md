Центр управления ярлыками LNK помогает централизованно управлять ярлыками Windows (.lnk). Благодаря полнотекстовому поиску, интеллектуальной группировке, напоминаниям об истечении срока, глобальным горячим клавишам и запуску в один клик вы сможете избавиться от хаоса, когда ярлыки разбросаны по рабочему столу и меню Пуск.

## ✨ Возможности

- **🔍 Полнотекстовый поиск** — Поиск в реальном времени через SQLite FTS5 с поддержкой префиксов, постраничной загрузки, истории поиска и подсветки ключевых слов
- **📁 Сканирование приложений** — Автоматическое сканирование приложений из меню Пуск, извлечение родных иконок Win32 и кэширование на диске (загрузка за миллисекунды)
- **🚀 Запуск в один клик** — Дважды щёлкните, чтобы запустить приложение, открыть файл, папку или URL, при этом автоматически отслеживается частота использования
- **🖥️ Глобальные горячие клавиши** — Настраиваемые глобальные сочетания (по умолчанию `Alt+Space`), обнаружение конфликтов и рекомендации
- **⏰ Напоминания об истечении срока** — Устанавливайте срок действия для временных файлов, получайте уведомления и удаляйте их пакетно по истечении срока
- **📚 Интеллектуальная группировка** — 8 цветовых групп, перетаскивание, пакетные операции, импорт/экспорт групп (JSON/CSV/HTML)
- **📦 Пакетный импорт** — Перетаскивание или выбор файлов для массового импорта с едиными настройками тегов, параметров и способа открытия, а также индикатором прогресса в реальном времени
- **🌐 Интернационализация** — Поддержка китайского, английского, французского, русского и арабского языков
- **🎨 Переключение темы** — Светлая/тёмная темы с сохранением пользовательских настроек
- **🖱️ Контекстное меню** — Интеграция с контекстным меню проводника Windows для быстрого добавления элементов
- **🔗 Глубокие ссылки** — Поддержка протокола `filemgmt://` для add/open/search/settings
- **🧩 Интеграция PPC** — Подключение к центральной системе PPC (v0.0.7) с сопоставлением кодов ошибок
- **🖥️ системный трей** — Скрытие в системный трей при закрытии, запуск через горячие клавиши или трей

## 📋 Системные требования

- **Операционная система**: Windows 10 / Windows 11
- **Среда выполнения**: Microsoft Edge WebView2 Runtime (предустановлен в Windows 11, требуется в Windows 10)
- **Разработка**: Rust 1.77.2+, Node.js 18+

## 🚀 Быстрый старт

### Режим разработки

```bash
# 1. Установите зависимости frontend
npm install

# 2. Запустите dev-сервер (порт по умолчанию 1420)
npm run dev
```

### Сборка для продакшена

```bash
# Рекомендуется: собрать полноценное приложение Tauri (frontend + встроенные ресурсы автоматически)
npx tauri build

# Сгенерировать установочный пакет (64-бит)
npx tauri build --target x86_64-pc-windows-msvc

# Сгенерировать установочный пакет (32-бит; сначала выполните rustup target add i686-pc-windows-msvc)
npx tauri build --target i686-pc-windows-msvc
```

Артефакты создаются в `src-tauri/target/<target>/release/bundle/` и содержат установщики `msi/` и `nsis/`.

> **⚠️ Важно**: запуск `cargo build --release` сам по себе создаёт испорченный бинарный файл, так как пытается подключиться к dev-серверу и может завершиться с ошибкой «Connection Refused». Всегда используйте `npx tauri build` или `cargo build --release --features custom-protocol`, чтобы корректно встроить frontend-ресурсы.
