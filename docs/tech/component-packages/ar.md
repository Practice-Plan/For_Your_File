# دليل إنشاء حزم المكونات

ابتداءً من الإصدار v0.0.5، تُنظَّم ميزات For_Your_File في صورة **حزم مكونات (Component Package)**. حزمة المكونات مستند JSON بسيط يعلن إعدادات مجموعة من الميزات؛ يقرأ المضيف هذه الإعدادات ويفسّرها و**لا يحمّل أو ينفّذ أي تعليمات برمجية من جهة خارجية**، لذا فإن استيراد حزم أنشأها آخرون آمن.

يُستخدم هذا المستند أيضًا مصدرًا لـ«دليل الإنشاء» داخل التطبيق (يعيد الأمر `get_component_creation_guide` هذا الملف).

---

## 1. بنية الملف

حزمة المكونات هي ببساطة ملف بامتداد `.json`:

```json
{
  "schema": 1,
  "id": "com.example.my-pack",
  "name": "我的组件包",
  "version": "1.0.0",
  "description": "一句话说明这个组件包做什么",
  "author": "你的名字",
  "kind": "theme",
  "components": [
    {
      "id": "appearance",
      "kind": "theme",
      "title": "我的配色",
      "config": { "accent": "violet" }
    }
  ]
}
```

## 2. الحقول

| الحقل | مطلوب | الوصف |
| --- | --- | --- |
| `schema` | نعم | إصدار الصيغة، وهو ثابت حاليًا على `1` |
| `id` | نعم | معرّف فريد. من 3 إلى 64 حرفًا؛ الأول حرف أو رقم، والباقي يمكن أن يكون `a-z` أو `0-9` أو `.` أو `-` أو `_`. يُفضّل الشكل `com.المؤلف.الاسم` |
| `name` | نعم | الاسم المعروض، من 1 إلى 100 حرف |
| `version` | نعم | أرقام مفصولة بنقاط، مثل `1.0.0` (من 1 إلى 4 مقاطع، أرقام فقط) |
| `description` | لا | نص الوصف |
| `author` | لا | معلومات المؤلف |
| `kind` | لا | نوع الحزمة، انظر أدناه؛ تركه فارغًا يعني حزمة عامة |
| `components` | لا | مصفوفة المكونات، 32 على الأكثر |

### كائن المكوّن

| الحقل | مطلوب | الوصف |
| --- | --- | --- |
| `id` | نعم | معرّف المكوّن، من 1 إلى 64 حرفًا |
| `kind` | نعم | نوع المكوّن، يستخدمه المضيف لاختيار طريقة التفسير |
| `title` | نعم | عنوان المكوّن (للعرض في الواجهة) |
| `config` | لا | كائن JSON حرّ، لا يتجاوز 256 KiB بعد التسلسل |

## 3. أنواع الحزم (kind)

| kind | الاستخدام |
| --- | --- |
| `theme` | المظهر: لون التمييز وحجم الخط والحركة وتفضيلات العرض الأخرى |
| `search` | سلوك البحث: استراتيجية الترتيب وحجم الصفحة وخيار تعدد اللغات |
| `workflow` | إجراءات سريعة: دمج أوامر موجودة في أزرار إجراء |
| `bundle` | حزمة مركّبة: تحمل في الوقت نفسه مكونات من أنواع متعددة |

## 4. اصطلاحات الإعداد

يقرأ المضيف `config` وفق `kind` الخاص بالمكوّن. المفاتيح المعروفة حاليًا مذكورة أدناه (المفاتيح غير المعروفة تُتجاهل وتُحفظ للإصدارات المقبلة):

### 4.1 `theme`

```json
{ "accent": "blue", "font_scale": "normal", "reduce_motion": false }
```

| المفتاح | القيم | الوصف |
| --- | --- | --- |
| `accent` | `blue` `violet` `emerald` `amber` `rose` | لون التمييز |
| `font_scale` | `small` `normal` `large` | حجم خط الواجهة |
| `reduce_motion` | `true` / `false` | تقليل تأثيرات الحركة |

### 4.2 `search`

```json
{ "sort": "relevance", "page_size": 50, "multilingual": true }
```

| المفتاح | القيم | الوصف |
| --- | --- | --- |
| `sort` | `relevance` `mostUsed` `recentlyOpened` `alphabetical` | ترتيب الفرز الافتراضي |
| `page_size` | عدد صحيح من 10 إلى 200 | عدد النتائج في الصفحة |
| `multilingual` | `true` / `false` | تفعيل مطابقة السلسلة الفرعية للكلمات غير اللاتينية (CJK، السيريلية، العربية وغيرها) |

### 4.3 `workflow`

```json
{
  "actions": [
    { "id": "rebuild-index", "title": "重建搜索索引", "command": "rebuild_fts_index" }
  ]
}
```

يجب أن يكون `command` اسم أمر مسجّل مسبقًا في المضيف (مثل `open_database_preview` و`rebuild_fts_index`). الأوامر غير المعروفة لا تُنفّذ، بل تُعرض معطّلة فقط.

## 5. الاستيراد والتصدير والحزم المدمجة

- **الاستيراد**: الإعدادات ← حزم المكونات ← استيراد، ثم اختر ملف `.json`. يُتحقق من schema وid والإصدار وkind وعدد المكونات وحجم الإعدادات؛ وتُرفض الحزمة غير الصالحة مع بيان السبب.
- **التصدير**: يمكن تصدير أي حزمة (بما فيها المدمجة) بصيغة JSON. يمكن استيراد الحزمة المستوردة كما هي مرة أخرى؛ أما الحزمة المدمجة المصدَّرة فتُستخدم قالبًا للإنشاء فقط — غيّر `id` قبل إعادة الاستيراد (معرّفات الحزم المدمجة محجوزة).
- **الحزم الافتراضية المدمجة**: ثلاث حزم جزء من ثنائي التطبيق:
  - `fyf.appearance.classic` — مظهر أزرق كلاسيكي
  - `fyf.search.balanced` — الصلة أولًا، 50 نتيجة في الصفحة، مطابقة متعددة اللغات
  - `fyf.workflow.quicklaunch` — إجراءات سريعة للصيانة
  يمكن تفعيل الحزم المدمجة أو تعطيلها، لكن **لا يمكن حذفها أو الكتابة فوقها** (معرّفاتها محجوزة).
- **موقع التخزين**: تُحفظ الحزم المستوردة في `components/packages/<id>.json` داخل دليل بيانات التطبيق، وتُحفظ حالة التفعيل في `components/state.json`.

## 6. قيود الأمان

1. حزم المكونات **تصريحية**: لا تحتوي على نصوص برمجية أو ملفات تنفيذية أو مراجع لموارد بعيدة، ولا ينفّذ المضيف أبدًا أي نص من الحزمة.
2. الحد الأقصى للملف 1 MiB، ولإعدادات المكوّن الواحد 256 KiB، ولعدد المكونات 32.
3. يجب أن تكون معرّفات الحزم فريدة؛ ولا يمكن استخدام معرّفات الحزم المدمجة.
4. تُتجاهل الحقول ومفاتيح `kind` غير المعروفة أو تُعرض للقراءة فقط، دون أن يتعطل التطبيق.

## 7. مثال أدنى: سمة بنفسجية مخصصة

```json
{
  "schema": 1,
  "id": "com.example.violet-theme",
  "name": "紫色夜间",
  "version": "1.0.0",
  "description": "紫色强调色 + 减弱动效",
  "author": "example",
  "kind": "theme",
  "components": [
    {
      "id": "appearance",
      "kind": "theme",
      "title": "Violet",
      "config": { "accent": "violet", "font_scale": "normal", "reduce_motion": true }
    }
  ]
}
```

احفظه باسم `violet-theme.json` ثم استورده داخل التطبيق.
