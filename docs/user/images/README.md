## Screenshot Requirements

### Format
- **File Format**: PNG (lossless)
- **Resolution**: Minimum 1920x1080
- **Color Depth**: 24-bit or 32-bit

### Content
- Clear, focused images
- No personal information visible
- Consistent UI state

### Themes
Capture screenshots in both:
- **Light mode**: `app-name-light.png`
- **Dark mode**: `app-name-dark.png`

### Annotations
When annotating:
- Use consistent arrow style
- Clear, readable text
- Highlighted areas clearly marked

## Naming Convention

Use descriptive names:
- `feature-name-action.png`
- Example: `search-interface.png`, `groups-create.png`

For multiple states:
- `dialog-open.png`
- `dialog-filled.png`
- `dialog-submitted.png`

## Creating Screenshots

### Windows Tools
- **Snipping Tool**: Built-in Windows tool
- **Snagit**: Professional screenshot tool
- **ShareX**: Free, open-source tool

### Recommended Settings
- Capture full window (not just content)
- Include window frame for context
- Show realistic data/examples

### Annotation Tools
- **Arrows**: Red or orange, 2px width
- **Highlights**: Semi-transparent yellow
- **Text**: Clear, readable font

## Placeholder Images

While actual screenshots are being created, placeholder images should:
1. Have correct dimensions
2. Indicate the content to be captured
3. Be in PNG format

## Updating Screenshots

When updating the application UI:
1. Review all screenshots
2. Update outdated images
3. Check for UI consistency
4. Update this README
