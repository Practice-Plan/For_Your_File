# Keyboard Shortcuts Reference

This document provides a complete reference for all keyboard shortcuts in LNK File Management Center.

## Global Hotkey

The global hotkey works from anywhere in Windows:

| Shortcut | Action |
|----------|--------|
| **Alt + Space** | Toggle search window (default) |

> **Note**: You can customize this hotkey in Settings > Hotkey.

## Search Window Shortcuts

### Navigation

| Shortcut | Action |
|----------|--------|
| **↑** / **↓** | Navigate through results |
| **Enter** | Open selected entry |
| **Escape** | Close search window |
| **Tab** | Move focus to filters |
| **Shift + Tab** | Move focus backward |

| Shortcut | Action |
|----------|--------|

| **Ctrl + Shift + F** | Toggle search filters |

## Customizing Shortcuts

### View Current Shortcuts

1. Open Settings
2. Go to Keyboard Shortcuts
3. View all shortcuts

### Modify Shortcuts

1. Click on a shortcut
2. Press the new key combination
3. Click "Apply"

### Reset to Defaults

1. Settings > Keyboard Shortcuts
2. Click "Reset All to Defaults"

## Shortcut Conflicts

### Common Conflicts

| Shortcut | Conflicts With |
|----------|----------------|
| **Alt + Space** | Some terminal applications |
| **Ctrl + K** | Browser search |
| **Ctrl + Shift + F** | Fullscreen in browsers |
| **Win + S** | Windows Search |

### Resolution

If a shortcut conflicts:

1. Settings > Keyboard Shortcuts
2. Find the conflicting shortcut
3. Click "Change"
4. Press new key combination
5. Save changes
