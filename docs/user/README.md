# LNK File Management Center - User Guide

## Welcome to LNK File Management Center

LNK File Management Center is a powerful Windows application designed to help you organize, search, and manage your Windows shortcut (.lnk) files efficiently. Built with modern technology, it provides a fast and intuitive interface for handling all your shortcuts in one place.

![Application Overview](./images/app-overview.png)

## Key Features

- **Lightning-Fast Search**: Find any shortcut instantly with real-time search
- **Project Groups**: Organize shortcuts into logical groups for better management
- **Expiration Reminders**: Set reminders for time-sensitive shortcuts
- **Cloud Synchronization**: Sync your shortcuts across multiple devices
- **Global Hotkey**: Quick access with customizable keyboard shortcuts
- **Context Menu Integration**: Add shortcuts directly from Windows Explorer
- **Smart Sorting**: Multiple sorting options including frequency and recency

## Quick Start

### First Time Setup

1. **Launch the Application**: After installation, LNK File Management Center starts automatically and runs in the system tray
2. **Initial Search**: Press `Alt + Space` (default) to open the search window
3. **Add Your First Entry**: Click the "+" button or use `Ctrl + N` to add a new shortcut
4. **Start Organizing**: Create groups to organize your shortcuts effectively

### Basic Usage

#### Opening the Search Window

- Press `Alt + Space` anywhere in Windows
- Or click the tray icon in the system tray

#### Adding a New Shortcut

1. Open the application window
2. Click the "Add Entry" button or press `Ctrl + N`
3. Browse to select a .lnk file, or drag and drop
4. Add tags and notes for better organization
5. Click "Save" to add the entry

#### Searching for Shortcuts

1. Press `Alt + Space` to open the search window
2. Type your search query
3. Results appear instantly as you type
4. Use arrow keys to navigate results
5. Press `Enter` to open the selected shortcut

## Navigation Guide

### Main Window

The main window consists of several key areas:

| Area | Description |
|------|-------------|
| **Title Bar** | Contains window controls and theme toggle |
| **Search Bar** | Central search input with instant results |
| **Results Panel** | Displays matching shortcuts |
| **Status Bar** | Shows result count and helpful tips |

### Sidebar (when expanded)

| Section | Purpose |
|---------|---------|
| **All Entries** | View all shortcuts |
| **Groups** | Browse by project/group |
| **Recent** | Recently used shortcuts |
| **Favorites** | Starred shortcuts |
| **Expired** | Shortcuts past their expiration date |

## Tips for Beginners

1. **Use Tags**: Add tags to your shortcuts for better searchability
2. **Create Groups**: Organize shortcuts by project or category
3. **Set Expirations**: Use expiration dates for temporary shortcuts
4. **Learn Shortcuts**: Use keyboard shortcuts for faster navigation
5. **Enable Sync**: Keep your shortcuts synchronized across devices
